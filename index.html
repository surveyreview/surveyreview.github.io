Abstract

Why this benchmark exists

SurveyReview turns real peer-review reports into a benchmark for evaluating automatic survey judges. The dataset converts free-form reviewer comments into structured scores and rationales across readability, criticalness, comprehensiveness, and structure, so model outputs can be compared against human review behavior instead of generic text quality signals.

The paper also introduces SurveyAlign, a strong baseline built on Qwen3-32B with LoRA and knowledge augmentation. On the test set, it improves reviewer alignment over GPT-5.2 by lowering average MSE from 2.28 to 1.38 and MAE from 1.15 to 0.69.

Overview

What the project contains

Benchmark design

Four dimensions reflect what reviewers actually judge in survey papers. Each example stores a discrete score and a supporting rationale, making the benchmark useful for both score prediction and reasoning evaluation.

Released artifacts

  • Reviewer-aligned dataset built from 675 survey papers and 1,630 reports.
  • Standardized train/test splits and evaluation protocol.
  • Baseline evaluator and reasoning-quality metric.
  • Public code repository for reproduction and extension.

Method

How SurveyReview is structured

01

Collect review reports

Use authentic peer-review comments from survey papers and convert them into a unified annotation schema.

02

Score four dimensions

Map each report into readability, criticalness, comprehensiveness, and structure with paired rationales.

03

Measure alignment

Report MSE, MAE, and reason-quality scores to quantify how closely automatic evaluators match human reviewers.

Results

Baseline performance snapshot

Key result

SurveyAlign is the paper's strongest baseline. It reduces average MSE from 2.28 to 1.38 and MAE from 1.15 to 0.69 on the benchmark test set.
